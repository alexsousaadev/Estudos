# Git: minhas anotações

## O que é o Git?

git é uma ferramente que pode ser utilizada offline que voce salva os arquivos em uma especie de camada que voce faz pelo seu computador é como se voce tirasse uma foto do seu celular

## Git x GitHub

A diferença é que um é como se fosse um programa instalado no computador para mexer, editar e criar repositorios e enviar para o github que é uma plataforma online, uma especie de nuvem, onde se armazena os repositorios e fica salvo todas as mudanças feito com o git

## Configuração inicial

Eu configurei o Git em meu computador, criando um repositorio no Github, e criei uma especie de chave para acessa-lo (segurança) o e-mail importa porque ele fica vinculado ao meu github, toda vez que eu faço um commit ou mexo no projeto ele aparece no meu perfil e o codigo utilizado foi o git config

## Chave SSH

O que fica comigo é a chave privada do projeto e o no git fica uma especie de chave publica para podermos entrar e sair do projeto, mas fica vinculada la para eu poder manusear o projeto com mais facilidade e com esta chave somente que da pra acessar o projeto, chave privada nao pode ser divulgada ou compartilhada com ninguem.

## O ciclo do dia a dia

git add ele prepara o arquivo que esta sendo utlizado para o commit, git commit voce digita a anotação e o que foi feito no arquivo, e o git push submete ao github

## Comandos que usei

- git add - ele prepara o arquivo para o commit
- git push - ele manda as coisas para o github no meu repositorio
- git commit apos o commit ele grava a versão no meu computador e somente o git push puxa a versão para o github
- git remote add origin ele registra diretamente o endereço do repositorio, falando pra ele a onde esta o repositorio 
- git status apresenta os status do meu repositorio e dos commits
- git init criou o arquivo oculto que nao pode ser apagado do projeto contendo o historico do projeto
